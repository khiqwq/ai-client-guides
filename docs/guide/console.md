# 控制台其他功能

|页面|用途|
|---|---|
|额度流水|账户额度的每笔变动与结余，含预扣、预扣退回、消费三类|
|发票管理|为已付款订单在线申请开票，可保存常用抬头|
|邀请好友|获取邀请码。好友首次充值，双方各获 5% 额度奖励；好友后续充值，邀请方获 2%|
|个人中心|修改用户名／邮箱／密码，启用两步验证与 Passkey，查看登录设备|
|工单支持|提交问题并跟进处理进度|
|系统公告|平台通知与维护公告|

建议在 **个人中心** 启用两步验证或 Passkey。账户余额与订阅均与账号绑定，账号安全直接关系到资产安全。

如有疑问，可提交 **工单支持**，或加入官方用户交流 QQ 群 **811416547**。
